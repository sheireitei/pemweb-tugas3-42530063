# ArtCraft Studio Inventory

Aplikasi berbasis web untuk manajemen inventaris stok perlengkapan seni (*art supplies*) dengan antarmuka bertema pastel dan sentuhan warna *lilac* yang estetik.

---

## Fitur Utama

- **Dashboard Inventaris**: Menampilkan daftar lengkap perlengkapan seni seperti kanvas, kuas, dan alat sketsa.
- **Operasi CRUD Lengkap**: Fitur untuk menambah, melihat, mengedit, dan menghapus data item inventaris.
- **Pencarian Real-time**: Memudahkan pengguna mencari peralatan seni tertentu dengan cepat.
- **Keamanan Basis Data**: Menggunakan *MySQL Connection Pool* dan *Prepared Statements* untuk mencegah kerentanan *SQL Injection*.

---

## Tech Stack

- **Backend**: Node.js, Express.js (Arsitektur MVC)
- **Templating Engine**: EJS (Embedded JavaScript)
- **Database**: MySQL
